# 4D FIT reference backend

A small Express API that implements every endpoint the Android app calls.
Good for local development and demos. For production, put it behind HTTPS
(a reverse proxy or a managed platform) and swap `src/store.js` for a real database.

```bash
cd backend
npm install
npm run smoke          # end-to-end test against a temporary database
JWT_SECRET=dev-secret npm start   # http://localhost:8080/v1
```

Security: passwords are hashed with bcrypt (cost 12) and never returned; sessions use
HS256 JWTs (set `JWT_SECRET` — required when `NODE_ENV=production`); auth routes are
rate-limited; request bodies are size-limited and validated.

| Method | Path | Auth |
|---|---|---|
| POST | /v1/register | – |
| POST | /v1/login | – |
| GET / PUT | /v1/profile | Bearer |
| DELETE | /v1/account | Bearer |
| GET | /v1/workouts, /v1/workouts/{id} | – |
| GET | /v1/nutrition/30-days | – |
| GET | /v1/horoscope/{zodiac}?date=YYYY-MM-DD | – |
| POST | /v1/workout/history | Bearer |
| GET | /v1/progress | Bearer |

Errors are JSON: `{"message": "..."}`. Content in `data/seed` is generated by
`tools/generate_seed.py` and shared with the app.
